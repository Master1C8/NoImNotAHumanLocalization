# No, I'm not a Human — VN Revival localization

VN Revival's standard localization and installation tools for No, I'm not a Human.
Published Windows and macOS downloads share one 14-language release. A licensed
copy of the game is required. Translation is supplied in the package; players do
not need a model account or a translation API key.

The published **0.2.1** packages target game **1.3.19**, build GUID
`c003ddc7de634775a85305fef3b9a0d3`. Windows uses x64; macOS requires macOS 14+
and the existing Sikarugir wrapper. Follow the matching platform instructions on
the download page. The repository includes localization and installer tooling;
it does not grant a license to redistribute the original game.

## Installation, recovery and development

Close the game and extract the complete archive before using the included installer.
Keep its resources together and preserve existing saves and original-file backups.
Use the package's recovery instructions; do not overwrite unknown modified files
or delete backups to bypass a conflict. The download page describes the exact
published package and contains installation instructions for both platforms.

The public release version is **0.2.1**. Legacy internal archive labels and bounded
QA receipts are historical evidence, not a different public release identity.
The existing published archives have verified SHA-256 values; their exact source
commits remain unknown. An installer base revision does not establish provenance
for the whole localization package.

## Authorship and verification

Maintained by [Anton / Master1C8](https://github.com/Master1C8) for VN Revival.
Codex is an AI development and translation tool, not a human editor. Human review,
Codex-assisted work and automated checks are separate activities; historical
receipts describe only the work and revision they actually cover.

Use the exact downloaded file's checksum and any recorded source-commit/build link
on the game page. The repository's latest branch is not evidence of an older
archive's source. SHA-256 proves byte identity; it is distinct from publisher
signing, Apple notarization, a build attestation and an independent security review.
This project is not affiliated with the original game's developer.
