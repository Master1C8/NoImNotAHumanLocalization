# Greek text final gate proposal

This directory is a root handoff for No, I'm not a Human 1.3.19, Russian to Greek, text only. It does not accept the locale, build a package, launch the game, or alter Git.

Run the read-only verifier from the canonical checkout:

```text
.venv/bin/python Translations/el/final-gate/verify.py
```

The verifier checks the complete first semantic pass (16,538 ordered source/target reads), the three correction cycles, the clean independent review03 delta (138 fresh accepted plus 1,566 exact prior decisions), the 1,269 unique mandatory IDs (39 fresh plus 1,230 reused), the 71 justified retirements, current authored hashes, source and glossary, static credits derivation, 2,831 repeated dialogue rows, and all 21 actual LocalizeItem consumers. The current corpus and canonical `preserve_exact.validate` receipts cover all 16,538 accepted IDs. Review03's manifest is `b79ebcb47a2a12e6664ae4a6b38690df6cd0ab07fa5c0174c63a7a8ba0501b17`.

The four cycle003 dialogue sidecars for batches 019, 024, 026 and 029 were the only administrative pins changed after review03. Their exact sealed bytes were archived first under `administrative-preimages/`; `administrative-refresh.json` maps each old pin to its archive and the current receipt. The authored batch bytes, source, glossary, closure and independent decisions were not changed. The current sidecars bind those four batches to the already passed fresh full-corpus guard. The verifier reconciles all 1,365 original input pins with exactly these four archived administrative preimages.

`root-handoff.json` uses the exact fields required by `Scripts/accept_locale_text.py`. Its `preserveExactReport` points to a current canonical `preserve_exact.validate` receipt generated by that module under this locale directory. `integration-plan.json` pins the proposed acceptance command, output path and current path/hash set. Root decides whether to run that command and owns any resulting receipt, build and Git integration.

Limits remain explicit: 29 historical dialogue keys have no compiled occurrence evidence; the old `OtherGameData` `m_Script` header differs from the native decode while gameplay fields and six deficit keys match. Greek rendering, fonts, layout, runtime, package, visual QA and publication were not tested here. Independent review03 is clean for the pinned text and closure; this author gate is not a new independent review or final runtime acceptance.
